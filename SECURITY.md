# Security and trust

Lens reads source as data and never installs dependencies, executes target code,
loads JavaScript config, initializes submodules or requires uploads/accounts.
Only explicitly trusted local binaries/tool packages may be selected as workers.

This unpublished development snapshot has no private reporting endpoint. Do not
post secrets or sensitive source publicly. When a maintained repository/contact
is established, replace this section with its verified private reporting channel.

Known limits include syntax-only comparisons, text guard identities, restricted
Windows descendant cleanup, synchronous extraction deadlines, and incomplete
broader-platform verification. See docs/lens-support.md. Findings are review
observations; zero findings never establishes that a merge is safe.
